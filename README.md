## About Me

I work on both halves of the problem. On one side that's deep learning — training and
tuning models in PyTorch and TensorFlow. On the other it's everything that has to exist
before a model is useful to anyone: the API in front of it, the frontend around it, the
database under it, and the network between them.

- Training models in **PyTorch** / **TensorFlow**, wrangling data with **NumPy** and **Pandas**
- Serving them over **FastAPI** and **Flask**
- Building interfaces with **React**, **Next.js**, and **Tailwind**
- Debugging what the wire is really doing in **Wireshark**
- Most at home in **Python**, also write **TypeScript**, **C/C++**, and **Bash**
